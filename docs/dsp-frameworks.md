# SDKs and DSP frameworks

Entries in `data/modules.yaml` tagged `type: sdk` are developer-facing
libraries, plugin APIs, or tools rather than end-user firmware.

Currently indexed:

| Manufacturer | Project | What it is |
| --- | --- | --- |
| Expert Sleepers | disting NT API | Plugin API for writing custom algorithms for the disting NT. |
| ALM Busy Circuits | ALM Firmware Updater | Cross-platform GUI flashing tool for ALM modules. |
| Intellijel | Firmware Updater | Browser-based flashing tool for Intellijel modules. |

Contributions of general-purpose embedded audio/DSP frameworks (not tied to a
specific module) are welcome — add them here and as `type: sdk` entries in
`data/modules.yaml`.
